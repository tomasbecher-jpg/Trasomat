# Trasomat

Trasomat je webová aplikace pro české kurýrní firmy (SMB), která plánuje a optimalizuje poslední míli.

## Vize
Pomoci malým a středním dopravcům plánovat trasy rychleji, levněji a spolehlivěji bez složitého TMS.

## Cílový segment pro V1
- České kurýrní firmy s 1-2 vozidly
- 20-30 zastávek denně
- Plánování typicky 1× ráno
- Aktuální workflow: Excel + Google Maps

## V1 (MVP) - co opravdu stavíme
1. **Dispatcher dashboard (web)**
   - Zadání depa, vozidel, směn a omezení
   - Import zastávek (CSV)
2. **Optimalizace tras**
   - Minimalizace času/kilometrů
   - Respektování časových oken, kapacity vozidel a priorit
3. **Výstupy pro řidiče**
   - Denní harmonogram
   - Export tras do Google Maps
4. **Základní KPI**
   - Celková vzdálenost, odhad času, odhad úspory

## Co je mimo V1
- Driver mobilní aplikace
- Pokročilé live přepočty během dne
- Pokročilé integrace (ERP/TMS)
- EN verze (v další fázi)
